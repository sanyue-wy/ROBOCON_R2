   SWA ─── 总使能（必须拨上才工作）
    SWC三种状态确定 Left_Y 的使用
        
车子运动永远由这三个确定
       Right_Y → 前后                   
       Right_X → 横移                   
       Left_X  → 旋转                   
       SWC处于下面
        Left_Y 用于夹爪那一块
        Left_Y处于最下面夹爪松开，舵机原装
        Left_Y处于中间夹紧
        Left_Y从中间到最上面旋转+90度，从最上面到中间先松开暂停一秒舵机恢复默认
      SWC处于中间
        Left_Y控制升降台高度
        SWB低车子下降，高车子抬升
      SWC处于上面
        Left_Y控制DOF1角度
        VRA控制DOF2
        VRB控制DOF3
        SWD低吸盘不吸，高吸盘吸住
